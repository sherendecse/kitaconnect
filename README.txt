KITA Connect — Final GitHub Pages Demo

READY-TO-UPLOAD VERSION
Extract the deployment ZIP. Upload index.html, .nojekyll and the entire assets folder to the root of your kitaconnect repository. Replace the earlier index.html and assets. Do not upload the ZIP itself or an enclosing folder.
GitHub Pages publishing source: main branch, / (root).
Website: https://sherendecse.github.io/kitaconnect/

This is a standalone browser-local demo. Records persist in the same browser; different devices do not share a database. No ChatGPT redirect or login is required. Use fictional details only.

EDITABLE SOURCE
Install Node.js 22.13 or later. In the source folder run:
  npm install
  npm run dev
To rebuild:
  npm run build
Upload the CONTENTS of dist/ to GitHub Pages after building. Keep .nojekyll in the publishing root.
